# ChatGPT Autopilot 0.3.0 (draft release notes)

**Status: draft for the release candidate. Not published; no tag.** The owner
publishes it only after approving the release candidate (docs/RELEASING.md).

ChatGPT Autopilot keeps a ChatGPT conversation working on your project: each
time ChatGPT finishes an answer, it waits a moment and sends your continuation
prompt. It is a continuation trigger, not an agent, and it has no server.

## Install

1. Download `chatgpt-autopilot-0.3.0.zip` below and unzip it into a folder you
   keep.
2. `chrome://extensions` → Developer mode → **Load unpacked** → that folder.
3. Reload any ChatGPT tabs that were already open.

Requires Chrome 116 or newer.

## What's in it

The first public release. Highlights:

- Automatic continuation with at most one continuation per finished answer,
  checked again on the live page before every send.
- Safeguards that pause or stop instead of guessing: your text in the message
  box is never overwritten, nothing is sent into another conversation, usage
  limits and errors are never retried, unknown notices pause.
- Optional *Stop on status marker*: ChatGPT's last line can stop or pause
  Autopilot; the answer is read only for that comparison.
- A clear panel: status with what to do, countdown, activity log, a *Page*
  line, a text-free diagnostic report, keyboard and screen-reader support.

## Known limitations

- ChatGPT's page changes over time; when it does, Autopilot stops with an
  error until it is updated.
- Notices are recognized in English only; in other languages they pause
  Autopilot. The Send button is recognized in English and Spanish, and in
  other languages where ChatGPT provides language-independent attributes.
- The panel is in English.
